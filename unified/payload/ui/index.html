Vera Runtime Host

Unified modular runtime package.

  • VeraMesh Edge — required live transport.
  • VeraRelay — bundled, disabled until qualified/configured; 0.2.0-0002 includes guarded standalone-state adoption.
  • VeraMesh Gateway — ARMv7 MCP/OAuth gateway, disabled until configured.
  • dsmctl — bundled ARMv7 DSM WebAPI CLI/MCP utility; no DSM credentials are provisioned.

Edge stays on 127.0.0.1:17445. Gateway stays on 127.0.0.1:17446 when enabled. WorkBridge remains external on Lappy and loopback-only behind VeraPort. Installation does not enable process execution or create public exposure.

Vera Mesh Edge

READY: LIVE_EDGE_PROXY_READY_DURABLE_RELAY_NOT_IMPLEMENTED

This package provides a loopback-only transparent TCP edge. Tailscale supplies tailnet-only ingress. VeraPort TLS and controller/workstation authentication remain end-to-end and are not terminated on the NAS.

Durable relay/store-and-forward is not implemented in V16.

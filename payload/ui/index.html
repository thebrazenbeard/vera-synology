Vera Mesh

Package mode: safe idle / unpaired

The VeraMesh package service may run normally in Package Center while network Mesh transport remains disabled in this repair candidate. It opens no TCP Mesh listener and performs no pairing or delivery.

Current Mesh semantic guard: BLOCKED_MESH_NOT_IMPLEMENTED.

Diagnostics

  • Package Center is the operator source for Start / Stop / running state.
  • The package-private local control socket reports runtime binding and installation-incarnation diagnostics to the test harness.
  • Any package start failure is a repair failure, not an expected state.

Semantic state vocabulary

  • UNPAIRED_READY
  • READY
  • DEGRADED
  • BLOCKED

Mesh transport itself remains BLOCKED until the separately reviewed Mesh core is integrated.
